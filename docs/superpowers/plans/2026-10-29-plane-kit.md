# plane-kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm plugin `plane-kit` (skill `plane-task`, hai lệnh `/plane-init` và `/plane-sync-ci`, script đồng bộ MR/PR → Plane cho GitLab và GitHub) và một nhánh Plane tùy chọn trong `git-mr` của release-kit; rồi chuyển CIMP-VBI sang dùng plugin.

**Architecture:** Plugin gồm prompt Markdown cộng một script Python phân phối kiểu vendored (`/plane-init` chép vào repo đích, kèm dòng `# plane-kit: vX.Y.Z`). Script đọc cấu hình qua biến môi trường và tách adapter nền tảng (`gitlab_event`, `github_event`) khỏi logic Plane dùng chung. Mọi thay đổi prompt và template được khóa bằng kiểm tra viết trước trong `scripts/validate.py`; script và hook có `unittest` riêng, `validate.py` chạy luôn chúng.

**Tech Stack:** Markdown prompts, Python 3 (stdlib; `jsonschema` chỉ cho `validate.py`), bash, git, YAML template (GitLab CI, GitHub Actions, lefthook).

**Spec:** `docs/superpowers/specs/2026-10-29-plane-kit-design.md`
**Nguồn gốc cần chuyển:** repo CIMP-VBI tại `/home/daont/workspaces/projects/sources/CIMP-VBI`: `shared/scripts/plane/plane_sync.py`, `shared/scripts/plane/tests/test_plane_sync.py`, `shared/scripts/git/add-plane-ref.sh`, `.gitlab/ci/plane.yml`, `.claude/rules/task-tracking.md`, entry `plane-ref` trong `lefthook.yml`.

## Global Constraints

- Regex mã item: `\b<identifier>-(\d+)\b`, không phân biệt hoa thường; `ABC-1` không khớp trong `XABC-1`. `identifier` khớp `^[A-Z][A-Z0-9]*$` (schema).
- Script luôn thoát 0; lỗi một item không chặn item khác; mỗi link/comment đăng đúng một lần theo marker; không in `PLANE_API_KEY`.
- Mặc định: `devBranch` = `dev`, `readyState` = `Ready For Testing`, `movableStates` = `["Backlog","Todo","In Progress"]`, `language` = `vi`, `branchPattern` = `{feature,fix,chore}/<identifier-lowercase>-<n>-<slug>`.
- Schema từ chối khóa lạ. `agentMaySet` là tập con của chính sách mặc định và không bao giờ chứa `Done`. Mã hóa chính sách bằng hai token: `inProgress` (đặt `In Progress`) và `ready` (đặt `readyState`); mặc định cả hai. (Quyết định khi lập kế hoạch: tên state của `readyState` đổi được nên `agentMaySet` không dùng tên state.)
- Biến môi trường của script: `PLANE_IDENTIFIER`, `PLANE_READY_STATE`, `PLANE_MOVABLE_STATES` (phân tách bằng dấu phẩy), `PLANE_DEV_BRANCH`, `PLANE_BASE_URL`, `PLANE_WORKSPACE_SLUG`, `PLANE_API_KEY`; GitHub thêm `GITHUB_TOKEN`. Chọn adapter bằng `GITLAB_CI=true` / `GITHUB_ACTIONS=true`, không thêm biến mới.
- Chuỗi comment/marker/log trong script giữ tiếng Việt như bản CIMP-VBI (idempotence theo marker); chỉ `devBranch` và nhãn `MR !N` / `PR #N` thay đổi. `language` chỉ chi phối skill.
- Dấu phiên bản: đúng một dòng `# plane-kit: v{{pluginVersion}}` ở dòng 1, hoặc dòng 2 nếu dòng 1 là shebang; `/plane-sync-ci` chỉ tìm trong 3 dòng đầu. Vị trí chép cố định trong repo đích: `.plane-kit/plane_sync.py`, `.plane-kit/commit-msg-refs.sh`, `.gitlab/ci/plane.yml`, `.github/workflows/plane-sync.yml`; `lefthook-refs.yml` là đoạn gộp vào `lefthook.yml`. Thư mục `tests/` không được chép.
- Placeholder trong template chỉ lấy từ khóa schema hoặc `pluginVersion` (cú pháp `{{key}}`); `movableStates` thế vào dạng chuỗi phân tách bằng dấu phẩy.
- GitHub: workflow khai báo `permissions: contents: read, pull-requests: read`; URL tag là `/tree/<tag>`, PR là `/pull/N`, commit là `/commit/<sha>`.
- File prompt (`commands/*.md`, `SKILL.md`, `README.md`) viết bằng tiếng Anh. Không bump version của release-kit; `plugin.json` của plane-kit bắt đầu ở `0.1.0`.
- Không dùng `git add .` / `-A`. Commit Conventional Commits, kết thúc bằng `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Nhánh làm việc `feature/plane-kit` cắt từ `dev`.
- Cổng kiểm tra: `python3 scripts/validate.py` (cần `jsonschema`). Chạy riêng test template: `python3 -m unittest discover -s plugins/plane-kit/templates/tests -v`.
- Changelog của repo này do `git-release` tổng hợp từ mục `## Changelog` của mô tả PR; **không** sửa `CHANGELOG.md` trong kế hoạch này (spec nói "thêm mục CHANGELOG" cho release-kit: làm bằng dòng `- Added:` ở mô tả PR của Task 9).
